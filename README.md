🛒 Shop Basket App

Ein modernes Frontend-Modul für einen Online-Shop-Warenkorb, entwickelt mit React und Redux Toolkit für das globale Statusmanagement und die interaktive Produktverarbeitung.

🚀 Funktionen und Merkmale

📦 Produktkatalog: Anzeige der verfügbaren Produkte mit Unterstützung für Seitennummerierung und Filterung.

➕ Warenkorb-Verwaltung:

Hinzufügen von Produkten zum Warenkorb mit dynamischer Aktualisierung der Anzahl.

Erhöhen / Verringern der Produktmenge.

Entfernen einzelner Artikel oder vollständiges Leeren des Warenkorbs.

💰 Automatische Berechnung: Sofortige Neuberechnung des Gesamtwerts und der Gesamtanzahl der Artikel.

💾 Zustandsspeicherung: Unterstützung für das Speichern des Warenkorbinhalts (über localStorage / API).

📱 Responsive Design: Korrekte Darstellung und Benutzerfreundlichkeit auf Mobilgeräten, Tablets und PCs.

🛠 Technologie-Stack

Frontend: React (JavaScript / TypeScript)

State Management: Redux Toolkit (RTK Query / Redux Slices)

Styling: CSS Modules / SCSS / Styled Components / Tailwind CSS (zutreffendes auswählen)

HTTP Client: Axios / Fetch API

Build Tool: Vite / Create React App

📦 Installation und Einrichtung

Führe die folgenden Schritte aus, um das Projekt lokal auszuführen:

1. Repository klonen

git clone https://github.com/OlegKhutorianskyi/shop_basket.git
cd shop_basket


2. Abhängigkeiten installieren

npm install
# oder
yarn install


3. Entwicklungs-Server starten

npm run dev
# oder
yarn dev


Nach dem Start ist die Anwendung unter http://localhost:5173 (oder http://localhost:3000) erreichbar.

🏗 Produktion-Build

Erstellen eines optimierten Builds für die Bereitstellung (Deployment):

npm run build
